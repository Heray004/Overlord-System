# Overlord System
**V 1.5**
___
### Описание
>Голосовой ассистент с моделью распознавания голоса vosk и собственной обученной моделью для 
>распознания команд. Overlord способен работать с n количеством микрофонов и сравнивать весь 
>распознанный текст для выведения точного запроса.
