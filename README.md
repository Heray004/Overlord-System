# Overlord System
**V 1.6**
___
### Описание
> Голосовой ассистент с моделью распознавания голоса vosk и собственной обученной моделью для 
> распознания команд. Overlord способен работать с n количеством микрофонов и сравнивать весь 
> распознанный текст для выведения точного запроса. Взаимодействие с устройтсвами умного дома
> через протокол Zigbee. Взаимодействие с устройствами, управляемыми ИК сигналом.
